# 🏝 Island Simulation

Многопоточная симуляция экосистемы острова.

Проект реализует модель взаимодействия животных и растений с учётом:
- передвижения
- питания (с вероятностью)
- размножения
- смертности

---

## 📌 Основная идея

Остров представлен в виде двумерного массива локаций (`Island` → `Cell[][]`).

Каждая клетка содержит:
- список животных (по видам)
- количество растений

На каждом такте симуляции:
1. Животные едят
2. Передвигаются
3. Размножаются
4. Умирают (если голодны или съедены)

---

## 🧱 Архитектура проекта

### Базовые классы

- `Animal` — абстрактный класс (общая логика)
- `Predator` — хищники
- `Herbivore` — травоядные

### Конкретные животные

Каждый вид реализован отдельным классом:
`Wolf`, `Fox`, `Bear`, `Rabbit`, `Mouse` и др.

### Модель мира

- `Island` — карта острова
- `Cell` — отдельная локация
- `Simulation` — управление симуляцией
- `StatisticsService` — сбор и вывод статистики

## ⚙️ Реализованная логика

- Ограничение количества животных на клетку
- Вероятностная модель питания (таблица)
- Проверка на наличие пищи в клетке
- Размножение при наличии пары
- Смерть от голода
- Рост растений

---

## ⚡ Многопоточность

Используются:

- `ScheduledExecutorService`
    - запуск тактов симуляции

- `ExecutorService`
    - параллельная обработка клеток

Это позволяет обрабатывать остров одновременно по нескольким потокам.

---

## 📊 Статистика

На каждом такте выводится:

- количество животных по видам
- общее количество животных
- количество растений
- карта плотности острова
