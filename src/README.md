# 🏝 Island Simulation

Симуляция экосистемы острова с животными и растениями.  
Проект реализован в рамках итогового задания (Module 2, JavaRush).

---

## 📌 Описание

Модель представляет собой остров в виде сетки локаций.  
Каждая клетка может содержать животных и растения.

Животные в симуляции:
- передвигаются
- питаются (растениями или другими животными)
- размножаются
- умирают (от голода или если их съели)

---

## 🧱 Архитектура

Проект построен с использованием ООП:

- `Animal` — абстрактный базовый класс
- `Predator` — хищники
- `Herbivore` — травоядные
- Конкретные классы животных (Wolf, Rabbit и др.)

Дополнительно:
- `Cell` — клетка острова
- `Island` — карта острова
- `Simulation` — управление жизненным циклом
- `StatisticsService` — вывод статистики

## ⚙️ Функциональность

✔ Передвижение животных по острову  
✔ Питание с вероятностью (таблица питания)  
✔ Размножение при наличии пары  
✔ Смерть от голода  
✔ Ограничение количества животных в клетке  
✔ Рост растений  
✔ Статистика по каждому такту  

---

## ⚡ Многопоточность

Используются:

- `ScheduledExecutorService` — для тактов симуляции  
- `ExecutorService` — для параллельной обработки клеток  

---

## 📊 Статистика

Каждый такт выводится:

- количество животных по видам  
- количество растений  
- карта плотности острова
